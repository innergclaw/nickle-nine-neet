## Storefront

The EP page keeps the full-EP purchase control above the track list and a single-track control beside each preview. Prices remain USD 2.99 per track and USD 14.99 for the EP.

Purchases are not live. Connect Stripe Checkout and protected full-song delivery before enabling the buy controls. Never commit full masters or payment secrets to this public repository.

The player supports pause, resume, one active track, and visible loading errors. EP-specific layout rules live in `assets/ep/store.css` so the artist profile keeps its existing design.
